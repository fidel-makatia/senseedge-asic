This report shows the GPIO configuration for your project based on:

GPIO Mode Reference:
----------------------------------------
GPIO 0-4: Fixed configuration (not user-configurable)

GPIO 5-37: Configurable GPIOs (can be set to user or management area):

Management Area Modes:
  0403: Input, no pull-up/down
  0c01: Input with pull-down
  0801: Input with pull-up
  1809: Output
  1801: Bidirectional
  000b: Analog

User Area Modes:
  0402: Input, no pull-up/down
  0c00: Input with pull-down
  0800: Input with pull-up
  1808: Output
  1800: Bidirectional
  1802: Output with monitoring
  000a: Analog
